# Medical Research PPT 使用申请

欢迎申请使用 Medical Research PPT 医学科研演示文稿技能。该技能仓库为私有仓库，访问申请由维护者人工审核。

## 申请方法

1. 使用您的 GitHub 账号登录。
2. [提交使用申请](../../issues/new?template=access-request.yml)，简要说明使用目的。
3. 维护者审核后，如同意，将向您的 GitHub 账号发送私有仓库邀请。请在 GitHub 接受邀请。

申请公开可见，请勿填写密码、邮箱授权码、患者信息、未发表数据或其他敏感信息。提交申请并不保证获得授权，也不代表自动授权；处理时间由维护者决定。

私有仓库访问权限可能包含写入权限，请遵循维护者的使用安排。已经获得授权的用户可使用有权限的 GitHub 账号访问技能仓库。
